Your own Kinetta in ten minutes.

Free for personal use. Needs a computer that stays on, with Docker.

01

Start it

Nothing to fill in.

git clone https://github.com/BenCBanks/kinetta.git
cd kinetta
docker compose up -d
02

Create your account

Open http://your-computer:8790. First account is admin.

# later, to update:
git pull
docker compose up -d --build
03

Reach it from your phone

See the connection guide.
