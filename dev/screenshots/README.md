# Fictional product captures

`scenes.json` is the shared website/App Store capture list. Each entry supplies a stable scene name, the app route (or the demo-record resolver in `take.js`), and any setup action. The same clean data comes from `dev/demo/seed.py`, `stage.py` and `coach.sql`. Activity uses three accepted fictional friends, plus a separate pending request; it shows a populated feed rather than a new-account discovery prompt. The Food story includes Add food, Nutrition, Insights and recipes. Retake after app design changes merge.

Start an isolated disposable Compose project with `compose.standin.yml`, load the fixtures, then run `take.js <png-directory> <base-url>` and `to_webp.py <png-directory> site/assets/shots`. Set the operator-approved map variables explicitly: the capture script blocks the public OSM tile endpoint. The website workflow reads only the published public `/api/map-config` through `map_env.py`, with no account or private runtime access. For localhost captures, its range-request relay uses the published app origin and adapts response CORS to localhost; archive bytes and rendering stay unchanged. No production CORS setting is changed. A visible map-load failure stops capture/publication. Food estimates, product lookup and prepared Kit reviews use labelled-in-documentation stand-ins, with no live AI or food-provider request. The screenshots show actual implemented browser controls and fictional records; they do not demonstrate model accuracy.

Website PNGs are whole393×852 browser viewports at2× (786×1704). The converter makes both393×852 `-1x.webp` and786×1704 `.webp` files, preserving the complete screen. Both themes use the same framing. `manifest.json` records the source revision and capture time; an open page refreshes each srcset candidate while preserving its density descriptor.

These website captures draw a simulated status/home bar and use browser safe-area substitutions. **They are not native iPhone or App Store evidence.** For #415, reuse the scene names, routes and fictional fixtures when capturing the actual6.9-inch UIKit Simulator at1320×2868. Do not resize these browser files into store screenshots. Native compilation, signed upload, App Store privacy answers, review and physical-device acceptance are separate release steps.
